                            EXECUTIVE SUMMARY

This project implements a Student Course Management System (SCMS) - a simple
desktop application designed to help students record and manage the courses they
are taking for a semester. The system provides a text-based menu interface with
all required functionality including adding courses, viewing all courses,
searching by course code, computing total units, and saving/loading course data
to/from files.

The application is built using Java's core Object-Oriented Programming concepts,
demonstrating proper class design, method usage, exception handling, file I/O
operations, and recursion. The system architecture separates the data model
(Course class) from the business logic (CourseManager class), providing a clean
and maintainable code structure.

================================================================================

                            1. PROJECT DESCRIPTION

Following the lab assessment guidelines, this system addresses the following
case study: "Student Course Management (Mini-System)". The purpose is to help
students track their courses for the semester with essential operations:

- Add new courses with code, title, and unit information
- Display all recorded courses in a clear format
- Search for specific courses using course codes
- Calculate and display total credit units
- Save course data to a file for persistence
- Load previously saved course data from a file

The implementation provides both a console-based interface and a graphical
user interface (Swing-based) to accommodate different user preferences.

                            5. CHALLENGES ENCOUNTERED

During development, the following challenges were addressed:

1. Scanner Input Management
   - Issue: Multiple Scanner objects causing "No line found" exceptions
   - Solution: Use single Scanner instance throughout, consume newline with
     scanner.nextLine() before recursive menu calls
   - Lesson: Always be aware of Scanner state and input stream positioning

2. File Path Consistency
   - Issue: Relative vs absolute path confusion between console and GUI
   - Solution: Default to "courses.dat" in working directory, allow
     command-line argument specification for file path
   - Lesson: Establish clear file path conventions early in development

3. GUI-Console Integration
   - Issue: GUI method calls to CourseManager methods needing updated signatures
   - Solution: Added getter methods (getTotalUnits(), getCourseList()) to
     CourseManager to expose necessary data to GUI component
   - Lesson: Design classes with proper encapsulation while providing
     controlled access for UI integration

4. Recursive Menu Design
   - Issue: Ensuring recursive menu properly terminates on exit
   - Solution: Explicit break on exit option (choice 7), all other options
     recurse back to menu display
   - Lesson: Always define clear base cases for recursive patterns

5. Data Validation Edge Cases
   - Issue: Empty strings, whitespace-only inputs, negative units
   - Solution: Comprehensive trim() calls, > 0 validation, null checks
   - Lesson: Validate inputs at every entry point, not just once

                            6. RECURSION APPLICATION

The recursion in this project is applied through the displayMenuRecursive()
method, which demonstrates a simple recursive pattern:

Method Signature:
  private void displayMenuRecursive(Scanner scanner)

Recursive Flow:
  1. Display main menu (options 1-7)
  2. Get user choice via showMenu(scanner)
  3. Switch on choice:
     - Cases 1-6: Perform operation, then call displayMenuRecursive(scanner)
     - Case 7 (Exit): Display farewell message, do NOT recurse (terminate)
     - Default: Invalid choice message, recurse to re-prompt

Purpose:
- Demonstrates understanding of recursion as required by lab assessment
- Provides natural menu looping without while/for loops
- Mimics real-world recursive problem-solving approach
- Clean termination on user request

The recursion is "tail-recursive" in nature - the recursive call is the
final action in each branch, making it an excellent educational example
of recursion in a practical application context.
